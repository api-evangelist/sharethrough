# Sharethrough

> Sharethrough is an omnichannel programmatic advertising exchange (SSP) for native, display,
> video and CTV inventory. Publishers monetise through header bidding and server-to-server
> OpenRTB; DSPs buy through the exchange. Sharethrough merged with Equativ in 2024 and, since
> June 2025, the combined company operates under the Equativ brand — the Sharethrough exchange
> and its endpoints continue to run.

Generated by API Evangelist from the artifacts in this repository. Sharethrough does not
publish an llms.txt of its own: /llms.txt returns 404 on www.sharethrough.com,
support.sharethrough.com and btlr.sharethrough.com, and 503 on publisher-api.sharethrough.com.

Note for agents: www.sharethrough.com/robots.txt disallows all crawling for every user agent,
including ClaudeBot, GPTBot, PerplexityBot, CCBot, MistralBot, cohere-ai, meta-externalagent
and OAI-SearchBot. Only /sellers.json and the sitemap sit outside that posture in practice.

## APIs

- [Publisher Reporting API](https://publisher-api.sharethrough.com/v2): POST /v2/programmatic
  runs a programmatic report for a publisher account. Bearer-token authentication. Request body
  carries startDate, endDate, groupBy, fields and filterBy; the response is CSV by default and
  JSON when Accept is not set to text/csv. GET /v2/health returns 200. The v1 surface is retired
  and answers 503.
- [Header Bidding / OpenRTB endpoint](https://btlr.sharethrough.com/universal/v1): the exchange
  bid endpoint used by the Prebid.js `sharethrough` bidder adapter. OpenRTB 2.x, unauthenticated,
  identified by a supply_id query parameter and a per-publisher `pkey` placement key.

## Machine-readable artifacts Sharethrough publishes

- [sellers.json](https://iab.sharethrough.com/sellers.json): IAB Tech Lab sellers.json 1.0.
  5,189 sellers (2,760 PUBLISHER, 2,143 INTERMEDIARY, 286 BOTH). TAG-ID d53b998a7bd4ecd2.
  Reachable as https://www.sharethrough.com/sellers.json, which 301s to the iab. host.
- [Device storage disclosure](https://assets.sharethrough.com/gvl.json): IAB TCF device storage
  and operational disclosure. Declares the stx_user_id cookie and the operational domains
  match., btlr., native. and *.rendering.sharethrough.com.
- [OpenID Provider Metadata](https://sharethrough-users.auth0.com/.well-known/openid-configuration):
  discovery for the company's Auth0 tenant, reached from the publisher platform login at
  nag.sharethrough.com.

There is no OpenAPI, no AsyncAPI, no GraphQL SDL, no MCP server and no A2A agent card. Every
standard discovery path was probed and missed; see well-known/sharethrough-well-known.yml.

## Authentication

- Reporting: `Authorization: Bearer <AUTH_TOKEN>`. An anonymous or invalid request returns
  `{"message":"Unauthorized","statusCode":401}` with no WWW-Authenticate header. Token issuance
  is not publicly documented.
- Bidding: none. Authorization is carried by the placement key, which Sharethrough issues after
  its Integrations team approves the publisher.

## Errors

Express/Nest default envelope, not RFC 9457: `{"message": string, "error": string?, "statusCode": int}`
served as application/json. Observed: 200, 204, 400, 401, 404, 503. No request id, no error codes,
no rate-limit headers.
